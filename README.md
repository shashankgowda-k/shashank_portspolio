# shashank_portspolio

A modern, high-performance Software Engineer portfolio website featuring interactive 3D WebGL graphics, Apple San Francisco typography, responsive vertical navigation, and technical glassmorphism.

## 🚀 Features

- **3D WebGL Interactive Core**: Rotating wireframe icosahedron, crystalline core, orbital concentric gimbal rings, and 260+ particle stars built with Three.js that dynamically track user cursor movements.
- **Physical 3D Card Tilt System**: Center-normalized perspective tilt and dynamic specular glare reflections across all cards (Projects, Skills, Experience, Contact).
- **Executive Technical Skills Matrix**: Categorized telemetry design with domain filter tabs (`Languages`, `Frontend`, `Backend`, `DevOps`) and illuminated proficiency progress meters.
- **Responsive Architecture**: Multi-device support across mobile, tablet, and desktop viewports, featuring an accessible slide-down vertical navbar for mobile screens.
- **Pure Black Technical Theme**: Pitch-black schematic backdrop (`#000000`), frosted obsidian glass surfaces, and responsive system theme detection with manual Night/Day mode switcher.

## 🛠️ Built With

- **HTML5** — Semantic, accessible web architecture
- **CSS3** — Custom properties, 3D perspective transforms, and media queries
- **JavaScript (ES6+)** — Interactive physics and filter engines
- **Three.js** — Real-time WebGL 3D rendering

## 🌐 Quick Start

Open `index.html` in any modern web browser:
```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```
